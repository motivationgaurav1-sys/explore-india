# Explore India 🇮🇳

Explore India is a multi-page travel website that showcases India's beautiful destinations, travel experiences, and attractions.

## 🌟 Features

- Home page introducing the website
- Destinations page showcasing places to visit
- Experiences page highlighting travel activities
- Gallery page displaying travel visuals
- Contact page for visitor enquiries

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

- `index.html` — Home page
- `destinations.html` — Travel destinations
- `experiences.html` — Travel experiences
- `gallery.html` — Image gallery
- `contact.html` — Contact page
- `css/style.css` — Website styling

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## 🎯 Purpose

This project was created to practice web development, page navigation, website styling, and organizing a multi-page website.
